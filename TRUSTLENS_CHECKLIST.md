# TrustLens Release Checklist

- [ ] Install dependencies and start the app locally.
- [ ] Check the example dataset and confirm that known issues are detected.
- [ ] Upload a clean CSV and confirm the findings update.
- [ ] Test a CSV with missing cells, duplicate rows, negative values, and invalid date values.
- [ ] Download and inspect the JSON report.
- [ ] Confirm the page title and visible branding say TrustLens only.
- [ ] Capture clear screenshots of the Overview, Issues & fixes, and Export report tabs.
- [ ] Review the limitations and avoid claiming features that are not implemented.
